# Contribuire

Grazie dell'interesse: miglioramenti, correzioni e segnalazioni sono benvenuti.

1. Apri prima una issue se la modifica è grande, così ci si accorda sulla direzione.
2. Lavora su un branch dedicato e mantieni la modifica piccola e focalizzata.
3. Aggiungi o aggiorna i test e lancia tutta la suite: `cd backend && npm test`.
4. Apri una pull request spiegando cosa cambia e perché.

Vulnerabilità di sicurezza: **non** in una issue pubblica, vedi [SECURITY.md](SECURITY.md).
